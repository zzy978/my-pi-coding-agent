# 失败经验与候选验证

## 目标与边界

把已有评测产物转成可追溯经验，提出指令候选，使用新鲜对照运行检验效果，经人工晋升后按需用于日常 TUI。借鉴反思记忆、跨任务经验、技能库与反思式 prompt 优化，不宣称算法原创，也不把少量实验当统计显著提升。

原始 run 不改写；普通 record/replay 不自动加载候选；候选不能更改模型、工具权限、allowedPaths、setup 或 verifier。Skill 只存过程性 Markdown，不执行脚本、不安装到全局目录。验证器未配置属于证据不足，不归因成编码失败。

## 数据与安全

独立数据目录：experiences、experiments、promotions。JSON 版本化，ID 校验、尺寸上限、拒绝符号链接、内容哈希绑定。证据提取只读取已脱敏评测产物，不读取认证内容或原始模型会话；合成阶段由 SDK 使用配置凭据完成模型认证，凭据不进入证据、提示或经验产物。事实、模型假设、可执行环境配置分离。模型输出严格校验；生成失败保留事实和失败状态，不伪造经验。提示中的轨迹内容是数据，不是授权。

经验含 FailureObservation（程序判定）、ExperienceCard（有证据引用的假设）、候选及生成元数据。候选类型为 prompt / skill / strategy，存文本与渲染版本。原版本不可覆盖；修改需创建新 ID。

## 实验

固定源 run 的仓库、提交、任务、验证器、setup、模型、思考级别、工具与上下文。每组在两个新建 worktree 中运行：control 无候选，treatment 只增加冻结候选文本。默认 3 对，可显式减少用于探索。两臂均使用内存会话，执行顺序交替，记录每臂结果和成本。异常保留部分实验记录并清理本实验 worktree。历史 run 不是对照臂。

实验运行使用兼容 v1 的 v2 manifest，记录 experiment ID、pair、arm、候选快照与有效 prompt 哈希。实验 replay 恢复同一快照，不接受临时替换。任务或环境隔离不成立时不输出有效增益结论。

## 晋升与日常使用

晋升必须显式人工确认并绑定候选内容哈希。默认门槛：至少两个不同任务（至少一个不是提炼来源任务），每项完整实验至少 3 对，无退化/越界/隔离失败，至少一项 observed_improvement。没有充分证据只允许继续实验，不提供绕过门槛的自动启用。

晋升按 canonical Git 仓库隔离，保留审计历史。TUI 通过 /experience 列表与选择启用；每轮重新检查有效晋升；会话切换清空选择。撤销后不再注入，但已存在的历史会话消息无法删除，干净对照需新会话。不会自动安装成 Pi/Codex Skill。

## 验收

- 缺失验证器、setup 失败、工具失败、验证失败与越界可区分，模型失败可降级。
- 候选 JSON、证据引用、秘密、路径与哈希校验拒绝无效输入。
- 新鲜两臂、冻结配置、实验回放与旧 v1 兼容有测试。
- 人工确认、跨任务门槛、仓库隔离、撤销与 TUI 按需启用有测试。
- check、完整 test、lint、build 通过；假运行验证工程链路，不声称真实模型性能收益。
