# SWE-bench Mini 同题经验复用实施计划

目标：运行固定 50 题的 R0、逐题 proposer 复盘、冻结经验、B；不增加第三组，不执行晋升。

已批准设计：本任务对话中用户选择 R0/B 前后比较并要求实现和运行。结果仅说明同题复用，不推断泛化或因果收益。

架构：宿主维护 Pi 会话、凭据和记录；唯一模型工具为策略包装的容器 Bash，容器无网络、无宿主挂载。官方 swebench 4.1.0 在独立评分容器中处理补丁和隐藏测试。模型不读取评分材料。数据、镜像 ID、配置、代码及经验哈希冻结，独立保存逐题检查点。

- [x] 协议与统计：测试数据白名单投影、重复 ID、经验完整性、缺失评分与 usage、配对胜负和两轮均成功 token；实现严格协议和报告。
- [x] 容器运行：测试替代 Bash 操作只暴露 bash、仍拒绝危险命令；接入容器超时、取消、无网络、补丁导出及官方评分。
- [x] 两轮编排：先完成全部 R0 再复盘，再冻结全部经验再 B；阶段检查点防止恢复时重付费，未知中断禁止自动重试。同题注入 proposer 的首个候选（固定规则，不根据 B 结果选择）。
- [x] 验证：check、lint、build 通过；完整 Vitest 374 项通过（单 worker，运行时限60秒，生产超时断言不变）；评分桥接3项通过；首题原始补丁红/参考补丁绿的实测通过。其余任务在正式模型调用前逐题完成同样检查。
- [ ] 实际执行：固定当前已配置模型与 high 思考级别，任务阶段上限若本机未配置则 15 分钟，每条工具命令最多 120 秒；逐题保存进度，真实执行 100 次并复盘，输出中文报告。

约束：保留现有 dirty worktree；不自动创建开发分支或提交；数据在 .picoding；不打印密钥；本轮追加的经验消耗计入 B；复盘成本单独统计；未完成和环境故障不能当成零 token 或修复成功。
